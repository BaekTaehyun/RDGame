PCG Cleanup 리팩터링

문제점

  • 레벨 로드 후 Clear 버튼 미동작: PCGRenderer가 UPROPERTY(Transient)로 선언되어 레벨 로드 후 null
  • ISM 컴포넌트 미삭제: PCG가 Owner Actor 내부에 직접 생성한 ISM 컴포넌트가 삭제되지 않음
  • 코드 중복: Cleanup 로직이 여러 곳에 분산

해결책

  • 통일된 Cleanup 방식: Owner Actor에서 모든 컴포넌트 직접 탐색/삭제
  • PCGRenderer null 대응: null이면 새로 생성 후 사용
  • 단일 책임: 모든 PCG cleanup 로직을 DungeonPCGRenderer::Cleanup()에 집중

Cleanup 순서

순서 대상 설명
1 UPCGComponent CleanupLocalImmediate + DestroyComponent
2 UInstancedStaticMeshComponent PCG가 생성한 ISM 컴포넌트 삭제
3 UStaticMeshComponent PCG가 생성한 SM 컴포넌트 삭제
4 PCGWorldActor PCG 시스템 캐시 초기화 (에디터 전용)

관련 파일

  • DungeonPCGRenderer.cpp: Cleanup(AActor*) 구현
  • DungeonRendererComponent.cpp: ClearDungeon() 호출부
