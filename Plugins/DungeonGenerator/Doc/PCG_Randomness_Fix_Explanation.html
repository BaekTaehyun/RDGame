PCG 난수 생성 및 갱신 문제 해결 보고서

🛠️ 문제 상황

Seed 값을 변경하고 "Generate"를 눌러도 PCG로 생성된 오브젝트들의 배치(Layout)가 변하지 않는 현상이 발생했습니다.

  • C++ 내부의 Grid 데이터는 정상적으로 변경되고 있음 (Checksum 확인 완료)
  • 하지만 PCG 그래프는 계속 예전 데이터를 사용하거나 실행되지 않음

🔍 원인 분석

두 가지 주요 원인이 복합적으로 작용했습니다:

  1. PCG 캐싱 (Caching): PCG 시스템은 성능 최적화를 위해 입력값이 같다고 판단되면 노드 실행을 건너뜁니다. 커스텀 노드(Dungeon Data Reader)가 "변경된 시드"를 제대로 알리지 못해 캐시된 데이터를 계속 사용했습니다.
  2. 컴포넌트 생명주기 문제: 코드에서 동적으로 생성한 UPCGComponent가 에디터 환경에서 너무 빨리 삭제되거나(GC), 관리되지 않아 실행 사이클을 놓치는 경우가 있었습니다.

✅ 해결 방법

1. 캐싱 강제 비활성화

커스텀 노드 설정(UPCGDungeonDataReaderSettings)에서 IsCacheable() 함수를 오버라이드하여 False를 반환하게 했습니다.

이로 인해 PCG 시스템은 이 노드를 만날 때마다 저장된 값을 무시하고 무조건 새로 실행하여 최신 Grid 데이터를 읽어오게 됩니다.

2. 컴포넌트 생존성 보장

SpawnedPCGComponents 배열을 만들어 생성된 컴포넌트들을 명시적으로 관리하고, 생성 방식을 Instance로 변경하여 에디터 내에서 정상적인 생명주기를 가지도록 수정했습니다.

3. 자동 갱신 연결

에디터에서 SeedOverride 값을 바꾸면 즉시 Generate()가 호출되도록 연결하여, 숫자만 바꿔도 바로바로 던전이 변하는 쾌적한 환경을 구축했습니다.

🎉 결론

이제 시드값만 변경하면 즉시 새로운 미로와 PCG 오브젝트 배치가 적용됩니다.
