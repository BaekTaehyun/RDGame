MCP PCG Integration Guide

This document explains how to set up the Unreal MCP Server and use it to control Procedural Content Generation (PCG) graphs from an LLM (like Claude Desktop).

Note: This setup requires Python support to be enabled in Unreal Engine.

1. Installation & Setup

Step 1: Prerequisites

  • Unreal Engine 5.2+ (with PCG Plugin enabled)
  • Python 3.x installed on the system (and Python Editor Script Plugin in UE)
  • Node.js (for the MCP Client, if using Claude Desktop)

Step 2: Script Placement

Ensure the following scripts are in your project's Script directory (e.g., Documents/Unreal Projects/RdGame/Script/):

  • unreal_socket_server.py (The Server)
  • unreal_mcp_bridge.py (The Bridge)

Step 3: Running the Server

The socket server must be running inside Unreal Engine to accept commands.

Option A: Manual Start

Run the following command in the Unreal Output Log (Cmd mode) or Python console:

py "c:\Users\COM2US\Documents\Unreal Projects\RdGame\Script\unreal_socket_server.py"
Option B: Startup Script

Add the line above to your `init_unreal.py` to start it automatically when the editor opens.

Step 4: Configuring MCP Client

Configure your MCP client (e.g., Claude Desktop config) to run the bridge script.

{
  "mcpServers": {
    "unreal-pcg": {
      "command": "python",
      "args": [
        "c:/Users/COM2US/Documents/Unreal Projects/RdGame/Script/unreal_mcp_bridge.py"
      ]
    }
  }
}

2. Using PCG Tools

Once connected, the LLM will have access to the following tools:

Create PCG Graph

Creates a new PCG graph asset.

  • Tool: create_pcg_graph
  • Args: package_path, asset_name

Add Node

Adds a node (e.g., Spawner) to the graph.

  • Tool: add_pcg_node
  • Args: graph_path, node_class (e.g., 'PCGStaticMeshSpawnerSettings'), position_x, position_y

Connect Nodes

Connects two nodes.

  • Tool: connect_pcg_nodes
  • Args: upstream_node (e.g. 'Input'), downstream_node

Assign Mesh (Smart Property)

Assigns a Static Mesh to a Spawner node. You can simply provide a list of asset paths.

  • Tool: set_pcg_node_properties
  • Example: 
    {
  "properties": {
    "MeshEntries": ["/Engine/BasicShapes/Cube.Cube"],
    "Debug": true
  }
}
