던전 생성 시스템: PCG 분리 리팩토링 완료

기존의 DungeonTileRenderer는 HISM(Hierarchical Instanced Static Mesh) 생성과 PCG(Procedural Content Generation) 생성을 동시에 담당하여 구조가 복잡했습니다. 이를 해결하기 위해 두 시스템을 명확히 분리하였습니다.

진행된 작업 (Completed Actions)

1. PCG 전용 렌더러 생성 (Separation)

UDungeonPCGRenderer 클래스를 새로 생성하였습니다. 이제 PCG 그래프 스폰 및 관리는 이 클래스가 전담합니다. 기존 렌더러는 순수하게 메쉬 타일 생성에만 집중합니다.

2. 데이터 접근 중앙화 (Centralization)

UDungeonRendererComponent가 이제 그리드 데이터(CachedGrid)를 중앙에서 관리합니다. 이를 통해 여러 하위 렌더러(Tile, PCG)나 데이터 리더들이 일관된 데이터에 접근할 수 있게 되었습니다.

3. 의존성 해결 (Dependency Resolution)

PCGDungeonDataReader가 더 이상 TileRenderer 내부를 뒤지지 않고, 컴포넌트를 통해 안전하게 데이터를 가져오도록 코드를 수정했습니다.

확인 방법 (Verification)

  1. 컴파일: Unreal Editor가 켜져 있다면, Ctrl + Alt + F11을 눌러 Live Coding 컴파일을 수행하세요.
  2. 재생성: 레벨 에디터에서 던전 생성 액터를 선택하고 Generate 버튼을 누르거나 액터를 이동시켜 재생성합니다.
  3. 결과 확인:
    • 기존 벽/바닥이 정상적으로 생성되는지 확인합니다.
    • PCG 그래프(문, 잡동사니 등)가 설정되어 있다면 정상적으로 스폰되는지 확인합니다.
