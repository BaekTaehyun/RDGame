🏰 Dungeon Generator + PCG Workflow

새로 구현한 Custom PCG Node (Pull 방식)를 사용하여 던전을 생성하고 꾸미는 전체 작업 흐름입니다.

1. PCG 그래프 생성 (에셋 준비)

각 던전 요소(문, 벽, 바닥 등)를 위한 개별 PCG 그래프를 생성합니다.

  • 콘텐츠 브라우저 우클릭 → PCG → PCG Graph 생성 (예: PCG_Dungeon_Door)
  • 그래프를 열고 "Dungeon Data Reader" 노드를 추가합니다.
  • 노드 설정(Settings)에서 Target Tile Type을 Door로 설정합니다.
  • Reader 노드 뒤에 Static Mesh Spawner 등을 연결하여 원하는 문(Door) 에셋을 배치하도록 구성합니다.
💡 팁: 벽(Wall), 바닥(Floor), 복도(Corridor)용 그래프도 동일한 방식으로 생성하되, Target Tile Type만 다르게 설정하면 됩니다.

2. 테마 에셋 설정 (연결)

DungeonThemeAsset에 생성한 PCG 그래프를 등록하여 던전 생성기가 이를 사용하도록 합니다.

  • 사용 중인 DungeonThemeAsset을 엽니다. (예: DA_DungeonTheme_Default)
  • PCG Settings 섹션을 찾습니다.
  • Compatibility Mode를 BSP로 설정합니다 (BSP 알고리즘 전용 기능 활성화).
  • Door PCG Graph 슬롯에 방금 만든 PCG_Dungeon_Door를 할당합니다.

3. 던전 생성 및 실행 (Runtime Flow)

게임 실행 시(또는 에디터 버튼 클릭 시) 내부적으로 일어나는 과정입니다.

  1. Generate Grid: DungeonLevelGenerator가 알고리즘(BSP)을 돌려 그리드 데이터(방, 복도, 문 위치)를 생성합니다.
  2. Cache Data: 생성된 그리드 데이터가 DungeonTileRenderer의 CachedGrid 변수에 저장됩니다.
  3. Spawn PCG: Renderer가 Theme에 설정된 PCG 그래프들을 위한 PCGComponent를 동적으로 생성합니다.
  4. Exec PCG (Pull): PCG 그래프가 실행되면서 "Dungeon Data Reader" 노드가 작동합니다.
    • 노드는 GetCachedGrid()를 통해 아까 저장된 그리드 데이터에 접근합니다.
    • 지정된 타일(예: 문)의 좌표를 찾아 PCG Point로 변환하여 출력합니다.
  5. Visual Spawn: 연결된 Spawner가 해당 포인트에 실제 메쉬를 생성합니다.

4. 확인 및 반복 (Verification)

  • 레벨에 배치된 DungeonLevelGenerator 액터를 선택합니다.
  • Generate Dungeon 버튼을 누릅니다.
  • 문(Door) 위치에 PCG로 설정한 메쉬가 생성되었는지 확인합니다.
  • 모양을 바꾸고 싶다면? C++ 재컴파일 없이 PCG 그래프만 수정하면 즉시 반영됩니다! 🚀
