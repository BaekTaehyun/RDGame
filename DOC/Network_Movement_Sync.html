🌐 네트워크 이동 동기화 시스템

TCP 기반 Dead Reckoning | BasePredictionTime + Jitter 방식

🎯 핵심 예측 공식

예측 위치 = 서버 위치 + 속도 × (BasePredictionTime + Jitter) 
// ReceiverStrategy.cpp
float Jitter = LocalDelta - ServerDelta;
ElapsedSec = BasePredictionTime + Jitter;  // 100ms + Jitter
FVector PredictedLocation = NewLoc + NewVel * ElapsedSec;

⚙️ 5단계 처리 파이프라인

1
경과 시간 계산
ElapsedSec = 100ms + (로컬패킷간격 - 서버패킷간격)
2
위치 예측
P = P₀ + V × t
3
중력 보정 (점프/낙하)
Z = Z₀ + Vz×t + ½gt²
4
방향 전환 보정
>45° 변경 시 목적지 90%로 단축
5
이상값 검증
거리 > 최대이동거리 시 원본 사용

🔧 상수 설정 (ReceiverStrategy.h)

상수 값 의미
BasePredictionTime 0.1f (100ms) 기본 예측 시간 (RTT/2)
MaxPredictionTime 0.5f (500ms) 최대 예측 상한
DirectionChangeThreshold 0.7f cos(45°) - 방향 전환 임계값
DestinationShortenRatio 0.9f (90%) 방향 전환 시 목적지 축소 비율
GravityZ -980.0f 중력 가속도 (cm/s²)
